## 3. Lệnh Chạy Kiểm Thử 1 Dòng
```bash
curl.exe -s http://localhost:3000/api/templates
```
Lọc theo template ID:
```bash
curl.exe -s "http://localhost:3000/api/templates?id=yt-animation-episode-v1"
```

---

## 4. Kết Quả Đo Lường & Bằng Chứng Cổng Nghiệm Thu
1. **Dữ liệu thật:** `curl` vào server Next.js đang chạy tại cổng 3000 trả về JSON thật 100%, chứa 8 template đầy đủ thông số v2 (`kind`, `tier`, `status`, `recipe`, `requires`, `outputs`, `sources`, `learned_from`).
2. **Kiểm tra điều kiện môi trường:**
   - 7 template Tier A (yêu cầu tools `bg-remove`, `stt-align`, `ffmpeg-bin` đã verified trong Toolbox) trả về:
     `is_available: true`, `missing_requirements: []`.
   - 1 template Tier B (`yt-animation-episode-v1` yêu cầu khóa Gemini): trả về:
     `is_available: false`, `missing_requirements: ["Thiếu khóa API nhà cung cấp 'gemini' (cấu hình trong Cài đặt hoặc .env)"]`.
   - Nếu template yêu cầu `gpu: true`: API tự động báo `Yêu cầu GPU NVIDIA phần cứng (máy hiện tại chỉ có CPU; cần dùng Tier A thay thế)`.
3. **Bộ lọc linh hoạt:** Hỗ trợ `?id=...`, `?category=...`, `?kind=...`, `?tier=...`.
