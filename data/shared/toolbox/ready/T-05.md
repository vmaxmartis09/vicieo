# BÁO CÁO SẴN SÀNG TEST — T-05: TÁCH NỀN (bg-remove)

## 1. Thông Tin Công Cụ
- **Tên tool:** `bg-remove` (Background Removal)
- **Engine:** `rembg` (u2net ONNX, CPU execution mode)
- **Giấy phép:** Code MIT, Weights Apache-2.0 (`commercial_ok: true`)
- **Vị trí tool:** `tool/toolbox/tools/bg-remove/` (venv độc lập)

## 2. Lệnh Chạy Thử 1 Dòng
```bash
py -3.11 tool/toolbox/toolbox_cli/cli.py run bg-remove --in tool/toolbox/tools/bg-remove/tests/sample_in.json --out tool/toolbox/tools/bg-remove/tests/sample_out.json
```

*(Hoặc dùng trực tiếp wrapper Windows nếu muốn: `tool\toolbox\toolbox.cmd run bg-remove --in ... --out ...`)*

- **Thư mục kho dùng chung:** `data/shared/assets/cutouts/71185678/`
  - Ảnh tách nền RGBA: `data/shared/assets/cutouts/71185678/cutout.png`

## 4. Kết Quả Đo Thực Tế
- **Ảnh mẫu thử nghiệm:** `data/projects/soc-nho-tv/characters/soc_nho/soc_nho_01.png` (Kích thước: 1024x572, định dạng PNG, chế độ đọc)
- **Thời gian xử lý trên CPU:**
  - Lần đầu (tự động tải u2net ONNX ~170MB): ~470s
  - Lần chạy tiếp theo (đã có model cache): **4.02 giây**
- **Kiểm tra kênh Alpha của cutout.png:**
  - Min alpha: `0` (trong suốt hoàn toàn, chiếm 82.8% diện tích)
  - Max alpha: `255` (đặc hoàn toàn, chiếm 0.6% diện tích)
  - Alpha bán trong suốt (1-254 khử răng cưa viền): 16.6% diện tích
  - Không có pixel nền trắng sót lại quanh nhân vật Bi.

## 5. Giới Hạn Đã Biết
- Model mặc định `u2net` tối ưu tốc độ và chất lượng đồng đều trên CPU.
- Với các chi tiết lông tơ siêu mảnh trong điều kiện ánh sáng nền trùng màu lông (#D96B27), có thể bật thêm `alpha_matting: true` trong params (thời gian chạy sẽ tăng thêm ~3-5s).
