## 2. Các thành phần đã triển khai
1. `tool/dashboard/components/templates/TemplateV2Card.tsx`:
   - Hiển thị poster xem trước (aspect 9:16 hoặc 16:9), tên, mô tả ngắn, danh mục.
   - Huy hiệu Tier (A/B/C) và Trạng thái (draft/runnable/verified) rõ ràng.
   - Biểu tượng yêu cầu phần cứng & tài nguyên: API Keys (`Key`), Toolbox Tools (`Wrench`), GPU (`Zap`).
   - Xử lý template thiếu điều kiện: làm mờ (`opacity-70 grayscale-[30%]`) kèm tooltip chi tiết từng điều kiện bị thiếu (theo Quy tắc 13).
   - Tương tác: Click đơn = chọn xem trước; Double Click = hộp thoại `confirm()` xác nhận dựng đồ thị trực tiếp vào Studio Canvas.
2. `tool/dashboard/components/templates/TemplateDetailDrawer.tsx`:
   - Drawer xem trước chi tiết (mở rộng với animation tween 0.22s `enterOnce`).
   - Trình phát video mẫu thực tế (nếu có MP4 thật) hoặc poster preview.
   - Nút bật/tắt Lưới an toàn Safe Zone TikTok/Reels (180px top / 320px bottom).
   - Chi tiết danh sách Slots tham số đầu vào, công thức đồ thị Studio (`recipe.nodes`).
   - Nút "Dựng đồ thị vào Studio" kích hoạt hàm sinh đồ thị `generateTemplateGraph`.
3. `tool/dashboard/components/templates/TemplatesView.tsx`:
   - Bộ lọc phân loại danh mục: Tất cả, KOC Review, Đánh giá sản phẩm, Hoạt hình, Motion Graphics, Vẽ tay, Thay nhân vật, Shorts Facts, Bản địa hóa.
   - Bộ lọc theo Tier phần cứng (Tất cả / Tier A CPU / Tier B API / Tier C GPU).
   - Thanh tìm kiếm từ khóa tức thời.
   - Ô nét đứt gợi ý tạo mẫu mới (theo Quy tắc 20, 22) khi ở cuối lưới hoặc khi danh sách trống.
   - Chỉ báo trạng thái tải dùng `AiLoading` chuẩn dự án.
4. `tool/dashboard/app/[locale]/templates/page.tsx`:
   - Trang `/templates` được tích hợp trọn vẹn vào layout và routing của Dashboard.
   - Đảm bảo i18n đầy đủ.
