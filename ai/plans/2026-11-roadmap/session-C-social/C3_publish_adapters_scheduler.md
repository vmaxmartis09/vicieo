# C3 — Adapter đăng bài chính chủ + Scheduler worker + Gói đăng tay

Bạn là Session C. Đọc: `CONTRACTS.md` (mục 3 an toàn), `status/C.md`, `social/*` (C1), `core/providers/key_vault.py` (cách lưu secret — chỉ dùng, không sửa), `core/providers/errors.py`, tài liệu chính thức (tra web nếu cần, ghi link vào docstring): YouTube Data API v3 `videos.insert` resumable + `thumbnails.set`; TikTok Content Posting API (Direct Post + Upload to inbox/draft); Meta Graph API (Facebook Page video, Instagram Reels container → publish).

## Nguyên tắc
- Chỉ dùng **OAuth chính chủ** do người dùng tự tạo app/client ID và tự bấm đồng ý; token lưu trong `key_vault` (`token_ref`), refresh tự động. Không lưu mật khẩu, không tự đăng nhập bằng mật khẩu, không vượt captcha.
- Không có quyền API (vd TikTok chưa được duyệt Direct Post, Douyin) → dùng **"Upload to inbox/draft"** nếu nền tảng hỗ trợ, nếu không → **Gói đăng tay** (manual package) + nhắc lịch. Tuỳ chọn `browser_assisted` (Ego Lite) chỉ *mở sẵn trang upload và điền sẵn caption*, **người dùng tự bấm Đăng** — không tự bấm nút publish.
- Không đăng gì khi `approval.required` mà chưa `approved`. Mọi lần đăng ghi `audit.jsonl`.

## Việc cần làm
1. **`social/adapters/base.py`**: `PublishAdapter` interface: `capabilities()` (direct_post, draft_upload, schedule_native, thumbnail, first_comment, product_link), `connect_url(account, redirect_uri)`, `exchange_code(...)`, `refresh(account)`, `validate(target, media) -> list[Issue]` (độ dài, tỉ lệ, dung lượng, codec), `publish(target, media) -> PublishResult{external_id, url, status}`, `fetch_status(external_id)`.
2. **`adapters/youtube.py`**: OAuth installed-app/web flow (`google-auth-oauthlib`) với `client_secret.json` người dùng đặt trong key_vault; upload resumable có tiến độ; set thumbnail; privacy; `publishAt` (lên lịch native khi private) ; made_for_kids; tags; category; playlist tuỳ chọn; Shorts (≤180s dọc tự nhận). Quota awareness (10k units/ngày, insert = 1600) → chặn sớm, báo lỗi rõ.
3. **`adapters/tiktok.py`**: Content Posting API: query creator info (privacy options, max duration), `init` FILE_UPLOAD chunked, Direct Post nếu scope `video.publish` có, không thì `video.upload` (vào inbox, người dùng hoàn tất trong app). Poll `status/fetch`.
4. **`adapters/meta.py`**: Facebook Page video (resumable), Instagram Reels (container → poll → publish). Cần Page/IG Business — validate và báo nếu thiếu.
5. **`adapters/manual.py`** (mọi nền tảng, kể cả Douyin/X/Threads): xuất `publishing/packages/<post>/<platform>/` (vùng C; video copy/hardlink từ output của A, không ghi vào `output/`) gồm `video.mp4` đúng biến thể, `cover.jpg`, `caption.txt`, `hashtags.txt`, `checklist.md`, `meta.json`; trạng thái target → `scheduled` với cờ `manual`; đến giờ → thông báo (C4 UI + `PushNotification` không có thì toast + badge) và nút "Tôi đã đăng" nhập URL → `published`.
6. **`adapters/browser_assisted.py`** (tuỳ chọn, tắt mặc định, bật trong settings account): dùng Ego Lite theo `CLAUDE.md` mục 2 để mở trang upload, đính file, dán caption, rồi **dừng chờ người dùng bấm đăng**; theo dõi URL thành công để lấy link. Không dùng cờ/stealth để né phát hiện tự động.
7. **Scheduler `social/scheduler.py`**: APScheduler AsyncIO (fallback vòng `asyncio.sleep(30)` nếu thiếu), mỗi 30s: lấy target `scheduled` có `scheduled_at <= now` và post `approved` → khoá target (`publishing`) → adapter.publish → `published`/`failed` (retry 3 lần backoff 2/10/30 phút cho lỗi tạm thời; lỗi vĩnh viễn như quota/auth → `failed` + lý do + account `expired`). Idempotent: không đăng 2 lần nếu crash giữa chừng (kiểm `external_id`/`fetch_status` trước khi đăng lại). Bật bằng env `SOCNHOTV_SCHEDULER=1` (mặc định bật khi chạy API, tắt trong test). Ghi heartbeat `publishing/scheduler.heartbeat`.
8. **API** (`routes/social.py`): `GET /accounts/{id}/connect` (trả URL OAuth), `GET /social/oauth/callback/{platform}` (đổi code, lưu token), `POST /accounts/{id}/refresh`, `POST /posts/{id}/targets/{tid}/validate`, `POST …/publish-now` (cần approved, có xác nhận phía UI), `POST …/mark-published` (manual, body url), `GET /scheduler/status`, `GET /packages/{post}/{platform}.zip`.
9. **UI** (vùng C): nút Kết nối OAuth trong `AccountCard` (mở cửa sổ, nghe callback), trạng thái token/quota; trong `TargetEditor` hiện `validate` issues; badge "Thủ công" + nút tải gói + "Tôi đã đăng"; trang `scheduler` nhỏ trong tab Bài viết (heartbeat, job sắp chạy, lỗi gần nhất).
